# Лабораторная работа №1

## Запуск

Для запуска фазз-тестирования:

```bash
make fuzz
```

Для запуска метаморфного тестирования:

```bash
make meta
```

Всё сразу:

```bash
make # or `make test`
```

**Предупреждение**: Нет доказательства завершимости.
